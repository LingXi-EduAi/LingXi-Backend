## 一、目标与完成定义

产品定位：面向真实教学流程的**多智能体协同学习系统**——学科智能体、调度智能体、评价智能体协同，覆盖教师备课 → 学生探究 → 作业批改 → 学情反馈闭环。

**统一对外口径**（对齐 mapping_road.md）：

> 灵犀教育不是一个简单的 AI 问答或教学管理平台，而是一个把教师备课、学生探究、作业批改、学情分析和个性化反馈连接起来的多智能体协同学习系统。

**系统级完成定义**（7 条）：

1. 仓库、构建产物、日志中无 Dify Key；凭据统一走环境变量。
2. 浏览器不直接调用 Dify；聊天、工作流、文件、会话全部经 LingXi 后端。
3. 登录用户有稳定且不可伪造的 Dify user 标识；前端无硬编码用户。
4. 查询、重命名、删除、停止会话或任务时强制校验资源所有者。
5. 任务可创建、流式执行、停止、断线恢复、失败子任务重试。
6. 认知轨迹、子任务、Agent、证据、最终回答可查看；刷新/断线不丢状态。
7. 教师可查看模型调用日志与分析页。
