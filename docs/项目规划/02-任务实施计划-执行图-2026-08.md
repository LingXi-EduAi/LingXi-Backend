# 灵犀（LingXi）— 任务实施计划·执行图（2026-08）

> 本文件按**功能板块**组织：每个板块 = 一个可独立交付的功能单元（后端 + 前端 + 测试一体），可直接整块交给 AI 实现。
> 每个板块统一六要素：**输入**（数据/前置条件从哪来）→ **输出**（交付物/数据流向哪）→ **实施内容**（要改动的代码与文件）→ **验收标准**（怎么算完成）→ **前置依赖** → **工作量**（人天）。
> 全局目标、比赛时间线、人员分工、风险与待决决策见 `01-项目规划-概览与分工-2026-08.md`。

## 一、系统数据流总览

```
用户输入 ──► POST /api/ai/tasks（AiTaskController）──► 创建任务(ai_task)
                        │
                        ▼
              DifyGateway（DifyGatewayImpl）──► Dify 应用（学科 Agent×N / 调度 / 反思 / 工具）
                        │  ← 用量：message_end.metadata.usage / workflow_finished.total_tokens
                        │  ← RAG：知识库检索命中 → 引用来源
                        ▼
        LingXiEvent 事件流：task_started → task_decomposed → agent_assigned
                  → node_progress → answer_delta → validation_finished → task_finished
                        │
     ┌──────────────────┼───────────────────────────────────────────┐
     ▼                  ▼                                           ▼
  ai_event          ai_message(提问/答案)                      ai_evidence(知识引用)
  (事件持久化)          ai_model_call_log(token/耗时/费用)             (A3 板块)
                     (A4 板块)        ai_feedback(反思/薄弱点/推荐)    │
     └──────────────────┼───────────────────────────────────────────┘
                        ▼
               SSE /api/ai/task/stream ──► 前端
                        ├─ SSE 客户端(FE-04) → Vuex ai 模块(FE-03)
                        └─ 工作台(FE-05)：流式答案 + 轨迹时间线(FE-06) + 会话侧栏(FE-10) + 反馈面板(FE-12)
会话身份：ai_task.conversation_id ──► lx_conversation（会话管理 A6/BE-11 读写）
反思回路：validation_finished → 反思/评价 Agent → ai_feedback → 个性化反馈（薄弱点+推荐练习）→ 学生/教师
```

主链路：用户提问经 `POST /api/ai/tasks` 进入 → 后端经 DifyGateway 调用 Dify → 返回以 `LingXiEvent` 事件流形态流出 → 并行落库（事件/消息/证据/模型日志）与 SSE 推送前端工作台渲染 → 会话历史经 A6 会话管理 API 从 `ai_message`/`lx_conversation` 读回。
