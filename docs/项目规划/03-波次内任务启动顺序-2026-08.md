# 灵犀（LingXi）— 波次内任务启动顺序（2026-08）

> 配套文档：`01-项目规划-概览与分工-2026-08.md`（大局）、`02-任务实施计划-执行图-2026-08.md`（板块）、`任务卡/`（58 个单任务交付单）。
> 本文件回答一个问题：**每个波次里，按什么顺序启动哪些任务？** 标注串行链（`→`）、并行窗口（`|`）、外部依赖（Dify 侧/平台）。

## 图例

- `A → B`：B 依赖 A，严格串行，必须等 A 完成再启动
- `A | B`：A、B 相互独立，可并行启动
- `⟲`：外部依赖（Dify 平台配置 / 云端服务），卡住不是代码问题，先确认外部状态
- 括号内为任务编号对应 `任务卡/*.md`

## Part A — 初赛冲刺（08-18 → 08-27）

### 波次 A0（第 0–1 天）— 基建与并行启动

**入口闸门**：无（首个波次）。

启动顺序：

```
QA-00-1(修 surefire) → QA-00-2(修失败测试)
QA-02-1(前端 vitest) | AUTH-01-1(鉴权审计) | FE-01-2(迁移 baseRequest) | DEMO-01-1(云端验证)
MAT-01 报告骨架（不依赖代码，即刻并行）
DIFY-01(学科+调度 Agent) → DIFY-02(反思 Agent+工具)   ⟲ Dify 平台
```

**并行窗口**：QA-02-1、AUTH-01-1、FE-01-2、DEMO-01-1、MAT-01、DIFY-01 共 6 条线同时开工。
**关键提醒**：DIFY-01/02 是平台配置（⟲），**不阻塞代码主线**，但必须在 A5 工作台联调前完成（演示依赖 Dify 侧能力）。

### 波次 A1（第 1–3 天）— 后端持久化 + 模型日志

**入口闸门**：QA-00-1、QA-00-2 完成（`mvn test` 可复现）。

启动顺序：

```
BE-10-1(AiMessage) → BE-10-2(AiEvidence) → BE-10-3(接入执行管线)
BE-13-1(AiModelCallLog) → BE-13-2(记录器) → BE-13-3(查询 API) → BE-13-4(导出)
DIFY-03(知识库 RAG)   ⟲ Dify 平台（依赖 DIFY-01/02）
```

**并行窗口**：BE-10 链 与 BE-13 链 相互独立，**可两链并行**（两名后端各领一条）。
**内部串行**：链内严格 `→`（实体 → Mapper → 服务接入）。

### 波次 A2（第 2–4 天）— 前端主线（严格串行）

**入口闸门**：QA-02-1 完成；FE-04-1 可与后端联调（契约已冻结，不阻塞）。

启动顺序：

```
FE-04-1(SSE 解析器) → FE-03-1(Vuex ai 模块) → FE-05-1(工作台) → FE-06-1(轨迹时间线)
```

**⚠️ 全项目最长串行链（5.5 人天）**：FE-04→FE-03→FE-05→FE-06 严格按序，中途不换人、不并行拆链。
**并行窗口**：无（链内）。

### 波次 A3（第 3–5 天）— 会话管理

**入口闸门**：BE-10-3 完成（`ai_message` 可写）。

启动顺序：

```
BE-11-1(会话列表+消息) → BE-11-2(重命名/删除/继续) → FE-10-1(侧栏接入)
```

**并行窗口**：BE-11-1 后端先行，FE-10-1 可等 BE-11-2 完成后再接入（前端在 BE-11-1 完成后即可先写 UI）。

### 波次 A4（第 4–5 天）— 退役清理 + 演示数据

**入口闸门**：FE-05-1 完成（工作台可替代旧页面）。

启动顺序：

```
FE-09-1(退役 TeachingAssistant) → FE-01-1(删 aiRequest)
DEMO-01-2(演示种子数据)   （依赖 BE-10-3、BE-11-1、BE-13-2 已就绪）
```

**并行窗口**：FE-09-1→FE-01-1 链 与 DEMO-01-2 相互独立。

### 波次 A5（第 5–6 天）— 云部署

**入口闸门**：FE-05-1、BE-11-1 完成。

启动顺序：

```

```

### 波次 A6（第 6–8 天）— 材料制作 + 缓冲

**入口闸门**：DEPLOY-01 完成（可在线演示）。

启动顺序：

```
MAT-04(截图) | MAT-03(日志导出+隐私说明)
MAT-02(演示视频，依赖截图与种子数据) → MAT-01 报告定稿
```

**并行窗口**：MAT-04、MAT-03 可并行；MAT-02 依赖部署稳定后录制。
**砍单备选**：时间不足先砍 FE-10-1（A3 已内嵌）、BE-13-4；**绝不砍 FE-05-1/FE-06-1/DEMO-01-2/MAT-02/DIFY-03**。

## 三条关键路径（全程盯防）

| 路径 | 链                                                           | 单点风险                            |
| ---- | ------------------------------------------------------------ | ----------------------------------- |
| 后端 | A0(QA-00) → A1(BE-10) → A3(BE-11)                          | BE-10-3 接入执行管线是唯一缝合点    |
| 前端 | A0(QA-02-1) → A2(FE-04→FE-03→FE-05→FE-06)                | **全项目最长串行链，不换人**  |
| Dify | A11(DIFY-01/02→DIFY-03) → B0(DIFY-04/05) → B1(DIFY-06/07) | ⟲ 平台配置，进度不可见，需每日确认 |

> **每日检查**：每波次结束时核对看板——本波次入口闸门是否满足、链上任务是否按序完成、⟲ 外部依赖是否就绪。
