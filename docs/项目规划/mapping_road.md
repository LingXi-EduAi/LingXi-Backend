# mapping road：灵犀教育三项比赛改进路线图

> 目标：把“灵犀教育”从现有的 AI 教育功能集合，升级为可用于大创、国创、智能体赛答辩与演示的“多智能体协同学习系统”。
> 
>

|比赛|评审重点|项目应突出内容|核心交付物|

|大创：浙江省国际大学生创新大赛（2026）|联通命题：跨学科、多智能体、认知轨迹、隐私保护、模型调用日志|“多学科智能体协同学习系统”|系统原型、技术方案、演示视频、模型调用日志、隐私保护说明|

## 二、当前项目基础

### 已有优势

1. 前端已有教师端和学生端双角色入口。

2. 教师端已覆盖教案、课件、AI 出题、作业、学情分析、班级管理等模块。

3. 学生端已覆盖 AI 助教、自测助手、作业中心、学习小组、学习资料和学情报告等模块。

4. 后端已有 Spring Boot 服务，覆盖用户、班级、作业、提交、批改、学情统计、学习小组等接口。

5. 已接入 Dify / 第三方课件生成等 AI 能力，具备快速演示基础。

### 主要短板

1. AI 功能目前更像多个单点工具，缺少“多智能体协同调度”的统一主线。

2. 学生学习过程缺少可解释的“认知轨迹”记录与可视化。

3. 部分学情分析仍有静态数据或固定数据，真实数据闭环不够完整。

4. AI Key、短信 Key、数据库密码等敏感配置存在硬编码风险，应迁移到环境变量并轮换。

5. 后端 README、部署文档、接口文档、测试和 CI 不足，不利于评审快速复现。

6. 比赛材料需要的模型调用日志、隐私保护说明、技术架构图、演示脚本尚需补齐。

## 三、统一产品主线

建议统一对外叙述为：

> 灵犀教育是一个面向真实教学流程的多智能体协同学习系统。它围绕教师备课、课堂任务、学生探究、作业批改和学情反馈形成闭环，通过学科智能体、任务调度智能体、评价反思智能体协同工作，帮助教师减负增效，并为学生提供个性化学习支持。
> 
> 

### 建议演示闭环

1. 教师输入一个跨学科任务，例如“设计一个低碳校园方案”。

2. 系统自动拆解任务，调用多个学科智能体：数学建模、科学原理、语文表达、艺术展示、评价反思。

3. 学生在 AI 助教引导下完成探究学习。

4. 系统记录学生提问、知识点迁移、错误修正、反思总结。

5. 教师端看到班级学情、薄弱知识点、优秀学生和需关注学生。

6. 系统生成个性化反馈、练习题和下一步学习建议。

## 四、功能改进路线图

### P0：安全与可运行基础（立即处理）

1. 移除前端和后端所有硬编码密钥。

2. 已暴露的 API Key、短信密钥、数据库密码全部轮换。

3. 所有 AI 调用统一走后端代理，前端不直接持有模型 Key。

4. 增加 `.env.example`，明确 MySQL、Redis、AI 服务、文件存储等配置项。

5. 增加 Docker Compose，一键启动前端、后端、MySQL、Redis。

6. 补充演示账号、演示班级、演示学生、演示作业和演示测验数据。

### P1：比赛核心亮点（优先开发）

1. 新增“多智能体协同学习”模块。

    - 学科智能体：数学、科学、文史、艺术。

    - 调度智能体：拆解任务、选择智能体、汇总输出。

    - 反思智能体：检查答案质量、提示改进方向。

2. 新增“认知轨迹可视化”模块。

    - 记录学生每次提问、AI 提示、知识点变化、错误修正。

    - 用时间线、节点图或 Sankey 图展示学习路径。

    - 支持教师查看单个学生和班级整体轨迹。

3. 新增“模型调用日志”模块。

    - 记录调用时间、用户、智能体、模型、输入摘要、输出摘要、耗时、token 用量。

    - 支持导出为比赛材料。

4. 改造学情分析。

    - 学生端从真实作业、测验、答疑数据生成个人报告。

    - 教师端从班级作业、测验、AI 使用行为生成班级报告。

    - 增加“薄弱知识点 → 推荐练习 → 后续跟踪”的闭环。

### P2：智能体赛专项增强

1. 增加 RAG 知识库。

    - 接入教材、课程标准、教师资料、历史作业。

    - AI 回答和出题需显示引用来源。

2. 增加工具调用能力。

    - 智能体可调用：创建作业、生成题目、生成课件、查询学情、生成报告。

    - 展示“不是简单问答，而是能执行教学任务”。

3. 增加防幻觉和边界提示。

    - 标注信息来源。

    - 对不确定答案给出“不确定/需教师确认”。

    - 高风险内容必须提示教师审核。

### P3：国创专项增强

1. 明确研究问题。

    - 多智能体协同学习是否能提升学生跨学科问题解决能力？

    - 认知轨迹反馈是否能提升学生作业质量和自我反思能力？

2. 设计实验方案。

    - 实验班 vs 对照班。

    - 前测、过程记录、后测、问卷和访谈。

    - 指标：作业完成率、平均分、薄弱知识点改善率、AI 使用频次、教师备课时间减少比例。

3. 规划成果。

    - 软件著作权。

    - 研究报告。

    - 校赛/省赛获奖。

    - 教育信息化或 AI 教育方向论文。

## 六、建议演示脚本

### 5 分钟版本

1. 0:00 \- 0:40：教育痛点。

    - 教师备课耗时长。

    - 学生个性化反馈不足。

    - 单点 AI 工具缺乏学习闭环。

2. 0:40 \- 1:30：系统介绍。

    - 灵犀教育是多智能体协同学习系统。

    - 覆盖教师端和学生端。

3. 1:30 \- 3:30：核心演示。

    - 教师发布跨学科探究任务。

    - 多智能体协同生成学习路径、题目和资料。

    - 学生与 AI 助教互动。

    - 系统记录认知轨迹。

4. 3:30 \- 4:30：学情闭环。

    - 教师查看班级学情。

    - 系统识别薄弱知识点。

    - 自动推荐练习和教学建议。

5. 4:30 \- 5:00：创新价值。

    - 多智能体协同。

    - 认知轨迹可视化。

    - 教育数据闭环。

    - 隐私保护和可解释机制。

## 八、最终定位

三个比赛可以共用同一套系统，但包装重点不同：

- 大创：强调联通命题下的跨学科多智能体协同学习。

- 国创：强调研究设计、创新训练和长期成果产出。

- 智能体赛：强调行业智能体、任务自主执行、RAG 和工具调用。

最终推荐口径：

> 灵犀教育不是一个简单的 AI 问答或教学管理平台，而是一个把教师备课、学生探究、作业批改、学情分析和个性化反馈连接起来的多智能体协同学习系统。
