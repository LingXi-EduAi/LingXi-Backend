# BE-14-1 — PII 脱敏（AOP + logback 正则 + 响应脱敏）

- **板块**：B2 隐私与安全加固（Part B 决赛，大创隐私）
- **波次**：B0
- **优先级**：Part B
- **前置依赖**：QA-00-1
- **工作量**：1 人天

## 目标

日志与响应中不出现手机号/邮箱/身份证/Dify-key/Authorization。

## 输入

- 既有 controller/service 日志输出
- `pom.xml`、`resources/logback-spring.xml`

## 实施内容

1. 新增 `config/MaskingAspect.java`：AOP 切面脱敏 controller/service 方法敏感参数。
2. 新增 `resources/logback-spring.xml`：logback converter 正则脱敏。
3. `pom.xml` 加 `logstash-logback-encoder`。
4. 测试断言脱敏输出。

## 验收标准

- 日志/审计/报告 JSON 无原始 PII。
- 测试断言脱敏输出。

## 工作区域

- 新增 `config/MaskingAspect.java`、`resources/logback-spring.xml`，`pom.xml` 加 `logstash-logback-encoder`，测试

## 约束

- Java 8。
- 不影响正常业务日志。
