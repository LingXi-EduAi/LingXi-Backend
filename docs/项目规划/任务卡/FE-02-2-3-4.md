## 目标

## 输入

- FE-02-1 的 `DifyProxyController`
- 5 个 iframe 页面 + `CoursewareHub.vue`（@docmee/sdk-ui 硬编码 token `ak_uKnjc...`）

2. `CoursewareHub` 的硬编码 token 迁到 env（`VUE_APP_DOCMEE_TOKEN`）或后端注入（**绝不在源码**）。
3. 移除 `VUE_APP_AI_API` 引用（确认零调用后从 `.env`/`.env.example` 删除）。
4. 手动确认每个 iframe 加载。
