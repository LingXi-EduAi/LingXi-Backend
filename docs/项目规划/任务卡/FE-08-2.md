# FE-08-2 — 防幻觉与边界提示

- **板块**：B5 子任务与证据面板（Part B 决赛，智能体赛"防幻觉机制"评审点）
- **波次**：B1
- **优先级**：Part B（智能体赛评审点）
- **前置依赖**：FE-08-1、B11（置信度数据）
- **工作量**：0.5 人天

## 目标

回答中的不确定性可视化——低置信度/无来源回答标注"不确定/需教师确认"（对应智能体赛"结果可解释 + 防幻觉"要求）。

## 输入

- A4/B11 的置信度与来源数据（`retrieval_finished` 事件、引用来源、无 RAG 命中的回答）；FE-08-1 证据抽屉

## 实施内容

1. `EvidenceDrawer.vue` 与 `AnswerPanel.vue` 增加状态标记：无引用来源或置信度低于阈值时渲染"⚠️ 此回答未经来源验证，建议教师确认"。
2. 工具 `safeMarkdown.js` 增加边界提示组件。
3. 阈值可配置（env 或常量）。

## 验收标准

- 无来源回答显示边界提示；有来源回答显示引用。
- 测试绿。

## 工作区域

- `EvidenceDrawer.vue`、`AnswerPanel.vue`、`safeMarkdown.js`

## 约束

- 纯 JS。
