# FE-02-1 — Dify iframe 代理层 `DifyProxyController`

- **板块**：B4 Dify iframe 代理迁移（Part B 决赛）
- **波次**：B0
- **优先级**：Part B
- **前置依赖**：A0
- **工作量**：1.0 人天

## 目标

浏览器全部经后端代理访问 Dify（完成定义 #2），`VUE_APP_AI_API` 可移除。

## 输入

- 现状：5 个 iframe 页面（SelfTestAssistant、AIQuiz、TeachingPlan、TeachingPlanPro、GradeHomework）经 `VUE_APP_AI_API` 拼 URL 直连 Dify

## 实施内容

1. 新增 `DifyProxyController`：`GET /api/proxy/dify/**` 流式转发 Dify webapp 响应，HTML/JS/SSE 友好头。
2. 代理转发保持 URL 路径、Cookie/凭据由后端注入（env）。

## 验收标准

- 代理端点可加载 Dify webapp 页面。
- HTML/JS/SSE 均正常转发。

## 工作区域

- 新增 `DifyProxyController`

## 约束

- 凭据只走后端 env，**绝不在前端源码**。
- Java 8。
