# QA-00-1 — 修 surefire，让 `mvn test` 真正跑 JUnit 5

- **板块**：A0 测试基建（Part A 初赛）
- **波次**：A0
- **优先级**：MUST
- **前置依赖**：无（首个任务）
- **工作量**：0.5 人天

## 目标

当前 `mvn test` 报 0 个测试（pom 未声明 surefire 版本，默认不支持 JUnit 5）。本任务让测试真正跑起来，作为后续所有板块的绿色闸门。

## 输入

- 后端 9 个既有 JUnit5 测试类（`src/test/java/**`）
- `LingXi-Backend/pom.xml`

## 实施内容

1. 在 `pom.xml` 的 `<build><plugins>` 中添加 `maven-surefire-plugin` 2.22.2。
2. **不要动** `spring-boot-maven-plugin` 的 `skip=true`（打包策略另行处理）。

## 验收标准

- `mvn test` 发现并运行 ≥9 个测试类（≥25 用例），输出 executed tests > 0（而非 0 tests run）。

## 工作区域

- `LingXi-Backend/pom.xml`

## 约束

- Java 8，不升级。
- 不改任何业务代码。
