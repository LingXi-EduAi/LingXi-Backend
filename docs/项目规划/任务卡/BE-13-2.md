# BE-13-2 — 模型调用记录器接入 DifyGatewayImpl

- **板块**：A4 模型调用日志（Part A 初赛）
- **波次**：A1
- **优先级**：MUST（大创硬性要求 + 视频证据）
- **前置依赖**：BE-13-1
- **工作量**：1 人天

## 目标

每次 Dify 调用（阻塞 + 流式）写一条日志。研究结论：用量在 `message_end.metadata.usage`（chat）与 `workflow_finished.data.total_tokens`（workflow）；**服务端载荷无模型名 → 服务端记录应用/工作流身份**。

## 输入

- `gateway/impl/DifyGatewayImpl.java` 的 `exchangeJson`/`startStream` 卡点
- BE-13-1 的 Mapper

## 实施内容

1. 新增 `service/AiModelCallLogService.java`（+impl，**异步**写入，不拖慢 SSE 路径）。
2. 在 `DifyGatewayImpl` 的 `exchangeJson`/`startStream` 卡点调用记录器：
   - `task_id`、`node_name`（应用）、`model`（应用/工作流 id 或 `"unknown"`）、`total_tokens`（有 usage 时）、`latency_ms`、失败时 `error_code`。
3. 编写 JUnit 测试。

## 验收标准

- 一次流式任务后 `ai_model_call_log` 含上述字段。
- 异步写不拖慢 SSE 路径。
- JUnit 测试绿。

## 工作区域

- 新增 `service/AiModelCallLogService.java`（+impl，异步）+ 测试
- 最小化修改 `gateway/impl/DifyGatewayImpl.java`（**不改网关公开 API 与凭据处理**）

## 约束

- Java 8。
- 凭据处理不动。
