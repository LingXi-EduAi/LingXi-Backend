# BE-12-2 — DifyGateway 从 DB/Redis 解析配置（缓存 + 回滚）

- **板块**：B1 Dify 应用配置管理（Part B 决赛）
- **波次**：B1
- **优先级**：Part B
- **前置依赖**：BE-12-1
- **工作量**：1.5 人天

## 目标

网关读取激活应用配置，Redis 缓存，支持切回旧版本无需重新部署。

## 输入

- BE-12-1 的 `dify_app_config` 表
- `gateway/impl/DifyGatewayImpl.java`
- Redis 既有配置

## 实施内容

1. 新增 `service/DifyAppConfigService.java`（+impl）：读取激活配置，Redis 缓存（TTL），支持切换/回滚。
2. `DifyGatewayImpl` 经 service 解析凭据（**不改公开方法**）。
3. 编写测试。

## 验收标准

- 配置表有当前 3 个应用时网关行为不变。
- 切换 `active`/version 在缓存 TTL 内生效。
- 回滚可用。
- 测试绿。

## 工作区域

- `gateway/impl/DifyGatewayImpl.java`（经 service 解析凭据）、新增 `service/DifyAppConfigService.java`（+impl）、测试

## 约束

- 不改网关公开 API 与凭据处理。
- Java 8。
