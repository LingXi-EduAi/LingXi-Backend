# BE-12-1 — Dify 应用/版本配置模型 + 迁移

- **板块**：B1 Dify 应用配置管理（Part B 决赛）
- **波次**：B0
- **优先级**：Part B
- **前置依赖**：QA-00-1
- **工作量**：1 人天

## 目标

Dify 应用 ID/版本/环境配置数据化（研究结论：用 git 内 DSL 管理版本；用 `workflow_id` 固定运行）。

## 输入

- `DifyGatewayImpl` 当前硬编码的 3 个 Dify 应用配置
- `sql/migrations/` 迁移模式

## 实施内容

1. 新增 `dify_app_config` 表（ai_ 风格）：varchar(32) PK、app_key、app_type、base_url、api_key 经 env 名引用、version、active 标志、checksum、时间戳、版本锁。
2. 新增 `pojo/DifyAppConfig.java`、`mapper/DifyAppConfigMapper.java`、`resources/mybatis/DifyAppConfigMapper.xml`。
3. 新增 up/down/verify 迁移脚本。
4. 编写测试。

## 验收标准

- 迁移 up/down/verify 可用。
- entity/mapper/XML 与既有风格一致。
- 测试绿。

## 工作区域

- `sql/migrations/` 新增、`pojo/DifyAppConfig.java`、`mapper/DifyAppConfigMapper.java`、`resources/mybatis/DifyAppConfigMapper.xml`、测试

## 约束

- Java 8。
- api_key 不落明文，只存 env 名引用。
