# BE-15-1 — 后端反馈生成 + `GET /api/ai/tasks/{id}/feedback`

- **板块**：B12 反思与个性化反馈（Part B 决赛，大创"个性化反馈"评审点 + 演示闭环第 4 段）
- **波次**：B2
- **优先级**：Part B（核心）
- **前置依赖**：A11、B11（反思 Agent 输出）、A3、A5
- **工作量**：1.0 人天

## 目标

个性化反馈闭环——任务完成后生成"反思结论 + 薄弱知识点 + 推荐练习 + 下一步建议"。

## 输入

- A11/B11 反思 Agent 的结构化输出（`validation_finished` 事件）；A3 落库的 `ai_message`/`ai_evidence`；A6 会话数据

## 实施内容

1. 在 `AiTaskExecutionServiceImpl` 任务完成处消费 `validation_finished` → 解析反思结构化内容 → 调用学科 Agent（或本地规则）生成"薄弱点 + 推荐练习"。
2. 落库（新增 `ai_feedback` 表或复用 `ai_message` 扩展，走迁移）。
3. 提供 `GET /api/ai/tasks/{id}/feedback`。

## 验收标准

- 任务完成后反馈可生成、可查询。
- 反馈内容基于真实事件（非固定文案）。
- JUnit 测试绿。

## 工作区域

- `AiTaskExecutionServiceImpl`（任务完成处，最小化）、新增 `ai_feedback` 迁移/实体/Mapper/Service、`controller`、测试

## 约束

- 不改状态机与乐观锁 SQL。
- Java 8。
