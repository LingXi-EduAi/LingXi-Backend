# MAT-02 — 5 分钟演示视频

- **板块**：A10 比赛材料（Part A 初赛）
- **波次**：A6
- **优先级**：MUST — 初赛交付物 #2
- **前置依赖**：DEMO-01-2、FE-05-1、FE-06-1、DEPLOY-01

## 目标

H.264 MP4 ≤5min/≤200MB，按 `mapping_road.md` 5 分钟脚本（痛点 → 系统 → 核心演示 → 学情闭环 → 创新价值），对已部署的工作台+轨迹+演示数据录制。

## 输入

- 已部署系统（DEPLOY-01）、演示数据（DEMO-01-2）、工作台（FE-05-1/FE-06-1）
- `mapping_road.md` 第六节 5 分钟脚本

## 实施内容

1. 按脚本录制：痛点 → 系统 → 核心演示（多智能体协同 + RAG 引用 + 工具执行 + 认知轨迹）→ 学情闭环 → 创新价值。
2. 剪辑至 ≤5:00，H.264 MP4，≤200MB。
3. 存档原始素材。

## 验收标准

- 文件在 `docs/交付材料/演示视频/`。
- H.264 MP4、≤5:00、≤200MB。
- 展示流式闭环 + 轨迹 + 会话历史 + 模型日志。

## 工作区域
