# BE-10-3 — AiMessage/AiEvidence 服务 + 接入执行管线

- **板块**：A3 消息与证据持久化（Part A 初赛）
- **波次**：A1
- **优先级**：MUST
- **前置依赖**：BE-10-1、BE-10-2
- **工作量**：1.5 人天

## 目标

真实运行持久化消息与证据，复用既有 `AiEventServiceImpl.record()` 事务缝（BE-09）。

## 输入

- BE-10-1 / BE-10-2 的实体 + Mapper
- `service/impl/AiTaskExecutionServiceImpl.java` 的 `ExecutionListener`（`onEvent`/`onComplete`）
- Dify 事件流：`message_end`（答案）、`node_finished`/`retrieval_finished`（证据形态）

## 实施内容

1. 新增 `service/AiMessageService.java`（+impl）：`saveUserQuestion`、`saveAssistantAnswer`、`getMessagesByConversation(id, page, size)`。
2. 新增 `service/AiEvidenceService.java`（+impl）：按 `message_id` 写证据。
3. 在 `AiTaskExecutionServiceImpl` 的 `ExecutionListener.onEvent`/`onComplete` 最小化接入：
   - 任务结束时写 `ai_message`：创建时 `role=user` 提问 + 回答时 `role=assistant` 答案，`dify_message_id` 取自 `message_end`。
   - 存在 `node_finished`/`retrieval_finished` 形态数据时写证据。
4. 编写 JUnit 测试。

## 验收标准

- 任务结束时 `ai_message` 有 `role=user` 提问行 + `role=assistant` 答案行。
- 有检索形态事件时写 `ai_evidence`。
- 按会话分页读可用。
- 既有事件流不变；JUnit 测试绿。

## 工作区域

- 新增 `service/AiMessageService.java`（+impl）、`AiEvidenceService.java`（+impl）及测试
- 最小化修改 `service/impl/AiTaskExecutionServiceImpl.java`（**不改状态机与乐观锁 SQL**）

## 约束

- 不动 `AiEventServiceImpl.record()` 签名/事务语义。
- Java 8。
