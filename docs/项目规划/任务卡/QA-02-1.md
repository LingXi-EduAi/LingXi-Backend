# QA-02-1 — 前端加 vitest 测试基建

- **板块**：A0 测试基建（Part A 初赛）
- **波次**：A0
- **优先级**：MUST
- **前置依赖**：无
- **工作量**：0.5 人天

## 目标

前端目前零测试基建，后续 FE-04/FE-03 需要。本任务搭好 vitest 测试环境。

## 输入

- `LingXi-Frontend/package.json`（vue-cli-service 5 项目）
- 现有 `vue.config.js`

## 实施内容

1. `package.json` 添加 devDependencies：`vitest`、`@vue/test-utils`（版本与 vue 3 兼容）。
2. 添加 `"test:unit": "vitest run"` 脚本。
3. 新增 `vitest.config.js`（与 `vue.config.js` 共存，不破坏 `serve`/`build`）。
4. 新增冒烟测试 `tests/unit/smoke.spec.js`。

## 验收标准

- `npm run test:unit` 跑通冒烟 spec 并退出 0。
- 与 `vue-cli-service serve/build` 共存无冲突。

## 工作区域

- `LingXi-Frontend/package.json`、`vitest.config.js`（新增）、`tests/unit/smoke.spec.js`（新增）

## 约束

- **不引入 TypeScript**（项目纯 JS 设计）。
- 不改 `vue.config.js` 行为、不动既有 views。
- 安装用 `npm install --legacy-peer-deps`（项目既有配置）。
