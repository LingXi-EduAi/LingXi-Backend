# BE-11-2 — `PATCH`/`DELETE /api/ai/conversations/{id}` + 继续对话

- **板块**：A6 会话管理（Part A 初赛）
- **波次**：A3
- **优先级**：MUST
- **前置依赖**：BE-11-1
- **工作量**：1 人天

## 目标

重命名、软删除、恢复会话（契约：PATCH/DELETE）。

## 输入

- BE-11-1 的 controller/service

## 实施内容

1. 扩展 BE-11-1 的 controller/service：
   - `PATCH /api/ai/conversations/{id}`：重命名更新 `lx_conversation`。
   - `DELETE /api/ai/conversations/{id}`：软删除（或级联删该会话 ai_* 行）。
   - "继续"：复用 `conversationId` 进入下一次 `/api/ai/task/stream`。
2. 所有权强制。
3. 编写测试。

## 验收标准

- 重命名/删除/继续全流程可用。
- 跨用户操作被拒。
- 测试绿。

## 工作区域

- 扩展 BE-11-1 的 controller/service 及测试
- `ConversationServiceImpl.java` 仅加增量方法

## 约束

- 所有权校验强制（AUTH-01-1 基线）。
- Java 8。
