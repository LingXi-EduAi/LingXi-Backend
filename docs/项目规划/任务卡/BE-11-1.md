# BE-11-1 — `GET /api/ai/conversations` + `GET /api/ai/conversations/{id}/messages`

- **板块**：A6 会话管理（Part A 初赛）
- **波次**：A3（后端先行）
- **优先级**：MUST
- **前置依赖**：BE-10-3
- **工作量**：1 人天

## 目标

会话列表 + 历史，供 FE-10（契约：分页会话、分页消息）。

## 输入

- `ai_task.conversation_id` / `lx_conversation`（会话身份）
- BE-10-3 的 `AiMessageService`

## 实施内容

1. 新增 `controller/AiConversationController.java`：
   - `GET /api/ai/conversations`：当前用户会话（来自 `ai_task.conversation_id`/`lx_conversation`），分页，每条带最后消息 + 任务状态；跨用户行排除。
   - `GET /api/ai/conversations/{id}/messages`：按会话分页 `ai_message`。
2. 新增 `service/AiConversationService.java`（+impl）。
3. `@Login` + 用户过滤强制。
4. 编写 JUnit 契约测试。

## 验收标准

- 列表/消息分页可用。
- 跨用户行排除（404/403）。
- 测试绿。

## 工作区域

- 新增 `controller/AiConversationController.java`、`service/AiConversationService.java`（+impl）、测试

## 约束

- 不动旧 `ConversationController` / `ApiController` 行为。
- **绝不基于 `lx_conversation.version` 比较**（DDL varchar(255) vs Java Integer 不一致）。
- Java 8。
