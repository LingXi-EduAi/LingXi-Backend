# 灵犀教育 · 隐私保护说明

更新日期：2026-09-12
适用：LingXi-Backend（后端 AI 链路）
对照实现：BE-14-1/2/3 与 BE-15 个性化反馈

## 1. 总体原则

1. 浏览器不直接访问 Dify；所有 AI 请求经后端中转，密钥、Token 与用户凭据只存在于后端环境变量。
2. 收集最小化：AI 链路只保存完成教学与个性化反馈所必需的任务、消息、引用、模型用量和审计数据。
3. 可追溯与可删除：提供保留期清理和按用户/会话/任务删除能力。
4. 如实声明：本说明只描述已实现能力，未接入项在文末单列。

## 2. 密钥与凭据保护

- 数据库、Redis、短信、Dify API Key 全部通过环境变量注入（`.env` 已 Git 忽略），仓库、构建产物、日志和响应中不含密钥。
- Dify API Key 由后端 `DifyGateway` 注入 `Authorization: Bearer`，前端不可见。
- 登录 Token 通过请求头 `token` 传递，不写入 URL 查询参数。

## 3. 访问控制与所有权校验

- `/api/ai/**` 全部要求有效登录 Token。
- 任务、会话、消息、反馈均按当前登录用户校验所有权；跨用户访问统一返回 404，避免资源探测。
- `/api/ai/tasks/{taskId}/feedback`、`/api/ai/conversations/**` 等接口不信任前端传入的归属字段。

## 4. 限流（防滥用）

- 对标注 `@RateLimit` 的接口按「用户 + 路径 + 时间窗口」计数，默认每用户每路径每分钟 60 次（`AI_PRIVACY_RATE_LIMIT_PER_MINUTE`）。
- 使用 Redis Lua 原子脚本完成计数与首次窗口设置，避免并发下窗口异常。
- 超限返回 HTTP 429，附 `Retry-After` 响应头，响应体保持 `status/msg/requestId/data` 结构。

## 5. 审计留痕

- `AiAuditInterceptor` 对 `/api/ai/**` 记录审计日志：用户 ID、请求路径、HTTP 方法、来源 IP、时间，落库到 `ai_audit_log`。
- 审计在鉴权放行后执行，不影响登录链路；审计日志随保留期策略一并清理。

## 6. 数据保留与删除

- 保留期可配置：`AI_PRIVACY_RETENTION_DAYS`，默认 90 天。
- 保留期清理：`POST /api/ai/privacy/purge`（教师权限），删除早于截止时间的 AI 数据。
- 按会话删除：`DELETE /api/ai/privacy/conversations/{conversationId}`。
- 按任务删除：`DELETE /api/ai/privacy/tasks/{taskId}`。
- 覆盖范围：`ai_message`、`ai_evidence`、`ai_event`、`ai_model_call_log`、`ai_audit_log`、`ai_task`，以及 BE-15 新增的 `ai_feedback`。
- 多表删除顺序为先删从属数据（消息/证据/反馈/事件），再删任务/会话，避免残留。

## 7. 敏感信息脱敏能力（已接入）

后端实现纯函数脱敏工具并配有单元测试（`PrivacyMaskerTest`、`PrivacyTextSanitizerTest`、`LogbackPrivacyConverterTest`）：

| 类型 | 效果示例 |
| --- | --- |
| 手机号 | `13800138000` → `138****8000` |
| 身份证号 | `110101199003071234` → `1101**********1234` |
| 姓名 | `欧阳娜娜` → `欧**` |
| 邮箱 | `zhangsan@example.com` → `zh***@example.com` |
| 自由文本 | 自动识别并掩码上述 PII |

已接入的链路：

- **日志输出**：`logback-spring.xml` 使用 `%maskedMsg`（`LogbackPrivacyConverter`）对所有日志正文自动脱敏。
- **错误信息落库**：`AiMessageService.saveAssistantError` 写入前对错误信息脱敏。
- **模型调用日志导出**：CSV/JSON 导出前对 `nodeName`、`model`、`errorCode` 等文本字段脱敏。

## 8. 当前实现边界（如实声明）

- 脱敏已覆盖日志、错误落库和模型调用日志导出；**尚未实现 AOP 级别的 controller/service 入参脱敏切面**（入参日志正文已由 Logback 转换器覆盖）。
- `lx_customer` 中的手机号/邮箱/姓名属于业务数据，当前由账户体系管理，未纳入上述文本脱敏链路。
- 模型调用日志当前按登录教师自身 `user_id` 过滤，教师查看学生数据的范围尚未冻结。
- 附件与消息内容的脱敏、保留范围尚未冻结。

## 9. 对应配置项

```properties
AI_PRIVACY_RETENTION_DAYS=90
AI_PRIVACY_RATE_LIMIT_PER_MINUTE=60
```
