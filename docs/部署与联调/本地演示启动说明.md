# 本地演示启动说明（联调/录屏用）

更新日期：2026-09-12
适用：在单台 Windows 机器上跑通「前端 → 后端 → MySQL/Redis → Dify」完整链路。

## 1. 依赖

| 组件 | 版本/位置 | 说明 |
| --- | --- | --- |
| JDK | 17（`C:\Java\jdk-17`） | 项目目标 Java 8；Spring Boot 2.6 建议 8/11/17，**不要用 21/23** |
| Maven | 3.6+ | |
| MySQL | 云库 `120.26.144.127:3306/lx` | 由后端 `.env` 的 `DB_URL` 指定 |
| Redis | 本地 `localhost:6379` | 未运行时登录会失败 |
| Node | 16+ | 前端 dev server |

## 2. 准备后端 `.env`

后端读取运行目录下的 `.env`（已在仓库外，含真实密钥，不提交）。至少确认：

```properties
DB_URL=jdbc:mysql://120.26.144.127:3306/lx?...
DB_USERNAME=...
DB_PASSWORD=...
REDIS_HOST=localhost
REDIS_PORT=6379
DIFY_CHATFLOW_BASE_URL=http://120.26.144.127:6004/v1
DIFY_CHATFLOW_API_KEY=...
```

## 3. 启动 Redis（二选一）

原生 Windows Redis（推荐，稳定）：

```powershell
Start-Process "C:\Program Files\Redis\redis-server.exe" "C:\Program Files\Redis\redis.windows.conf"
& "C:\Program Files\Redis\redis-cli.exe" ping   # 期望 PONG
```

或 WSL Ubuntu（网络转发可能不稳）：

```bash
wsl -e bash -lc "redis-server --daemonize yes; redis-cli ping"
```

## 4. 启动后端（端口 5678）

```powershell
$env:JAVA_HOME = "C:\Java\jdk-17"
cd <LingXi-Backend>
mvn -o -DskipTests compile
mvn -o -q dependency:build-classpath "-Dmdep.outputFile=target/runtime-classpath.txt"
$cp = "target\classes;" + (Get-Content target\runtime-classpath.txt -Raw).Trim()
& "C:\Java\jdk-17\bin\java.exe" -Dfile.encoding=UTF-8 -cp $cp com.lxe.lx.LxApplication
```

启动成功：`Started LxApplication`，端口 5678。

## 5. 启动前端（端口 8080）

在 `LingXi-Frontend` 新建 `.env.development.local`（已被 git 忽略）：

```properties
VUE_APP_BASE_API=http://localhost:5678
VUE_APP_AI_API=http://120.26.144.127:6004
```

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
npm.cmd run serve
```

访问 http://localhost:8080 。

## 6. 演示账号与数据

- 教师：`demo-teacher-0001 / 123456`（可看模型日志、班级用量、轨迹回放）
- 学生：自行注册，或使用现场注册的账号（工作台流式问答）
- 演示种子数据：执行 `sql/seed/demo_ai_data.sql`（幂等，可重复导入；DEMO 前缀，不污染业务数据）

```powershell
mysql --default-character-set=utf8mb4 -h <host> -u <user> -p lx < sql/seed/demo_ai_data.sql
```

> 导入含中文 SQL 必须带 `--default-character-set=utf8mb4`，否则报 1064/1366。

## 8. 常见问题

| 现象 | 处理 |
| --- | --- |
| 登录返回「登录失败/人员不存在」 | 检查 Redis 是否运行（`redis-cli ping`） |
| 创建任务 500 / `ERR value is not an integer` | 确认使用修复后代码（限流已改 `StringRedisTemplate`） |
| 前端连不上后端 | 检查 `.env.development.local` 的 `VUE_APP_BASE_API` 与后端端口 |
| 轨迹回放空白 | 事件必须是 LingXiEvent v1 小写类型；重新导入最新 `demo_ai_data.sql` |
| `mvn clean` 删不掉 target | 先停止正在运行的后端进程（占用日志文件） |
